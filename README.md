# Part 4 - testing backend


### To run the application in production : `npm start`
### To restart the application whenever files change: `npm run dev`

### to run tests sequentially : `npm test -- test-concurrency=1` 

### to run parts of tests that are "test.only": `npm test -- --test-only`
### to run the application in dev environment ```npm run dev``` 
### to run the application in test environment ```npm run start:test```
